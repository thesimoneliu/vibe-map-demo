# Vibe Map demo

A touch-friendly recreation of the interaction in the supplied reference image. Open `index.html` in a browser, or visit the published GitHub Pages URL.

- Tap or drag the point to choose between solo/social and buzzing/chill.
- Tap a category icon to change the lens while keeping your position.
- Send a message to add it to the conversation. Simple English and Chinese mood keywords move the point; other text leaves its position unchanged. All responses are scripted in the browser.
- On a keyboard, focus the point and use arrow keys. Hold Shift for larger steps.

No API, account, location permission, or build step is required.
